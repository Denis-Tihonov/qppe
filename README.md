# Phase extraction of quasiperiodic signal using time-delay embedding
The paper investigates a phase extraction problem of a quasiperiodic signal.
These are repetitive signals with changes in period and frequency.
We propose an algorithm of expected phase extraction.
The original time series is presented in the phase space with time delay embedding.
This embedded time series forms phase trajectory of initial system.
The phase of the signal is reconstructed using the approximation model of an expected phase trajectory.
Also the paper proposes the criterion for choosing the optimal dimension of the trajectory subspace.
The results are shown on signals that were collected from the three-axis accelerometer.
Five classes of human motion are used.
For quality analysis, the algorithm is compared with the method that uses autocorrelation peaks, Hilbert transform and autoencoder.
